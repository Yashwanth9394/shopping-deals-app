# Shopping Deals App

A deal aggregator and tracker application that scrapes and displays the best shopping deals, deployed on AWS Amplify.

## Features

- Deal aggregation from multiple sources
- CSV-based deal database
- Search and filter deals
- Responsive web interface
- AWS Amplify deployment

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Data:** CSV parsing
- **Deployment:** AWS Amplify
- **CI/CD:** amplify.yml pipeline

## Getting Started

### Local Development
Open `index.html` in your browser or serve with any static file server.

### Deployment
Push to the connected GitHub branch - AWS Amplify auto-deploys via `amplify.yml`.
